                            关闭时：页面 URL 含 index.php（如 /index.php/search），API 始终通过 /api/index.php 访问，不依赖任何重写规则，开箱即用。

                            各环境规则文件：

                            • Apache：项目根目录 .htaccess，自动生效（需 mod_rewrite + AllowOverride 含 FileInfo）

                            • IIS：项目根目录 web.config，需安装 URL Rewrite 模块

                            • Caddy：使用 Caddyfile，执行 caddy run --config Caddyfile

                            

                            Nginx 宝塔面板快捷操作：网站 → 设置 → 伪静态 → 粘贴 nginx.conf 内容 → 保存

                        一键安装失败？查看手动安装方法
                        

                            
如果一键安装失败（如服务器禁用了 shell_exec 函数），请根据服务器系统手动安装：

                            
 Linux（在终端执行）：

                            
curl -fsSL https://ollama.com/install.sh | sh
systemctl start ollama
systemctl enable ollama
ollama pull llama3.2

                            
 Windows：

                            
REM 方式1：下载安装包（推荐）
REM 访问 https://ollama.com/download/OllamaSetup.exe 下载并运行

REM 方式2：使用 winget
winget install Ollama.Ollama

REM 安装后拉取模型
ollama pull llama3.2

                            
 macOS：

                            
brew install ollama
brew services start ollama
ollama pull llama3.2

                            
或者使用云端 API（无需安装）：在下方选择 DeepSeek 等服务商，填入 API Key 即可。
