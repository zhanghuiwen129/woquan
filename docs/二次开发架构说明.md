## 4. AutoLoader

| 命名空间前缀 | 目录 |
| --- | --- |
| `Hublog\Core\` | `api/core/` |
| `Hublog\Controllers\` | `api/controllers/` |
| `Hublog\Middleware\` | `api/middleware/` |

| 规则 | 值 |
| --- | --- |
| 注册 | `spl_autoload_register([AutoLoader::class, 'loadClass'])` |
| 解析 | 最长前缀回溯，`str_replace('\\','/',$relativeClass).'.php'`，`file_exists` 后 `require_once` |
| 子目录 | `api/core/Exception/`、`RealName/`、`Sms/`、`UploadProvider/` 由 `Hublog\Core\` 前缀 + 子路径解析 |
| 插件 | `Plugin::load()` 直接 `require_once`，按 `Hublog\Plugin\{name}\Plugin` 取类并调 `init()` |
| composer | 运行时零依赖，入口不加载 `vendor/autoload.php`；`vendor/` 仅供 PHPUnit 与 CI |
| `composer.json` | 无 `autoload` 段；`require-dev` 仅 `phpunit/phpunit: ^10.5` |

`Hublog\Bootstrap\` 由 `bootstrap.php` 直接 `require_once` 引入。

## 5. 中间件链

### 5.1 分组

| 组 | `api/routes.php` 行 | 前缀 | 中间件（按执行顺序） |
| --- | --- | --- | --- |
| 顶层独立 | `10` `13` `14` | `/api/csrf`、`/sitemap.xml`、`/robots.txt` | `RateLimitMiddleware` |
| 顶层独立 | `26`（`/api/health` 27）、`32`–`33` | `/health`、`/api/health`、`/api/metrics`、`/metrics` | 无 |
| 公开组 | `36`–`176` | `/api` | `RateLimitMiddleware`、`CsrfMiddleware`、`LicenseMiddleware`、`FeatureGuardMiddleware` |
| 钱包 / 会员组 | `179`–`205` | `/api` | `RateLimitMiddleware`、`AuthMiddleware`、`CsrfMiddleware`、`LicenseMiddleware`、`FeatureGuardMiddleware` |
| 支付回调组 | `209`–`212` | `/api` | `RateLimitMiddleware`、`FeatureGuardMiddleware` |
| 需登录组 | `215`–`390` | `/api` | `RateLimitMiddleware`、`AuthMiddleware`、`CsrfMiddleware`、`LicenseMiddleware`、`FeatureGuardMiddleware` |
| 管理组 | `393`–`626` | `/api/admin` | `RateLimitMiddleware`、`AuthMiddleware`、`CsrfMiddleware`、`AdminMiddleware`、`LicenseMiddleware` |

路由级中间件通过 `$router->get($path, $handler, ['MiddlewareName'])` 追加，组中间件在前、路由级在后。中间件返回 `Response` 实例即短路。

### 5.2 六个中间件

| 中间件 | 入口 | 失败输出 |
| --- | --- | --- |
| `RateLimitMiddleware` | `handle(Request): void` | `HublogException(429)` |
| `AuthMiddleware` | `handle(Request): void` → `Auth::check()` | 401 / 403 / 500 |
| `CsrfMiddleware` | `handle(Request): void` | `HublogException('CSRF验证失败', 403)` |
| `LicenseMiddleware` | `handle(Request): void` | `HublogException(..., 402)` |
| `AdminMiddleware` | `handle(Request): void` | `HublogException('权限不足', 403)` |
| `FeatureGuardMiddleware` | `handle(Request): ?Response` | `Response::error('该功能未开启', 4230)`，HTTP 200 |

| 常量 | 内容 |
| --- | --- |
| `MODULE_ROUTES` | 8 个模块 `ai` / `scheduled` / `dataops` / `circles` / `shop` / `finance` / `activities` / `realname`；`finance` 排除 `#^/api/pay/notify/#` |
| `AI_QUOTA_ROUTES` | `#^/api/ai/#` |
| `RESOURCE_WRITE_ROUTES` | 注册、发帖、编辑、三种上传共 6 条 |
| `NEVER_BLOCK` | `/api/admin/`、`/api/auth/`、`/api/app/config`、`/api/site/config`、`/api/pay/notify/`、`/api/cron/`、`/api/csrf`、`/health`、`/sitemap.xml`、`/robots.txt` |
| 站点模式 guard | `off`（默认）/ `log` / `on`；`off` 直接返回，`log` 只写日志 |

`AdminMiddleware` 对 `/api/admin/activities` 与 `/api/admin/my-circles` 放行圈主（按 `circles.owner_id` 判定）。`Auth::check()` 校验 `token_version` 与 `status = 1`。

## 6. 基类与数据访问

### 6.1 `BaseController`

| 方法 | 签名 / 作用 |
| --- | --- |
| `paginate` | `(Request, $sql, $params, $countSql, $countParams, $formatter=null, $defaultLimit=20, $listDecorator=null): Response` |
| `clearCache` | `(string $prefix): void` → `Cache::deleteByPrefix()` |
| `currentUser` / `currentAdmin` | `(Request): ?array` |
| `requireUser` / `requireAdmin` | `(Request): array`，未登录抛 401 |
| `formatSize` | `(int $bytes): string` |
| `fetchGiteeApi` | `(string $url): ?array`，先 `Security::validateOutboundUrl`，超时 10 秒 |
| `upsertSetting` | `(string $key, string $value, string $now): void` |

### 6.2 `Database`

| 方法 | 签名 / 说明 |
| --- | --- |
| `getInstance` | `(): PDO`；`ATTR_EMULATE_PREPARES=false`、`ERRMODE_EXCEPTION`、`FETCH_ASSOC` |
| `query` | `(string $sql, array $params = []): PDOStatement`，`prepare()` + `execute()` 真预处理 |
| `fetchOne` / `fetchAll` / `fetchColumn` | `(string, array = [])` |
| `insert` | `(string $table, array $data): int`，校验表名与字段名，返回 `lastInsertId()` |
| `update` | `(string $table, array $data, string $where, array $whereParams = []): int` |
| `delete` | `(string $table, string $where, array $params = []): int`，拦截无条件删除 |
| `beginTransaction` / `commit` / `rollBack` | 事务 |
| `getStats` | `(): array` → `query_count` / `query_time` |
| `validateName` | `(string): bool`，`/^[a-zA-Z0-9_]+$/` |

表名与列名必须走 `validateName`；动态拼接的标识符一律先校验。无 Model 层与 ORM，Repository 类平铺在 `api/core/`：`PostRepository.php`、`UserRepository.php`、`SettingsRepository.php`。

### 6.3 `Request`

| 类别 | 方法 |
| --- | --- |
| 取参 | `get($key,$default=null)`、`query(string $key,?string $default=null)`、`all()`、`has()`、`setParam()` |
| 类型转换 | `getInt`、`getString`、`getArray`、`getFloat`、`getBool`（`1/true/on/yes`） |
| 头 / 令牌 | `getHeader(string)`、`getBearerToken()` |
| 文件 | `getFiles()`、`getFile(string)` |
| 元信息 | `getMethod()`、`getPath()`、`setPath()`、`getIp()`、`pagination($default=20,$max=50)` |

`parseInput()`：GET 用 `$_GET`；非 GET 解析 `php://input` 的 JSON 并与 `$_GET` 合并。`getIp()` 仅在 `REMOTE_ADDR` 命中 `TRUSTED_PROXIES` 时解析 `X-Forwarded-For` 最左段。

### 6.4 `Response`

| 方法 | 说明 |
| --- | --- |
| `success($data=null, $message='success')` | `code=200` |
| `error($message='error', $code=400)` | `data=null` |
| `toJson()` | `{code,message,data}`，`JSON_UNESCAPED_UNICODE` |
| `normalizePayload()` | 空 `avatar` 补默认图；`http(s)://` / `data:` / `//` 原样；`images` `videos` `attachments` 尝试 JSON 解码；`/uploads/ /assets/ /templates/` 前缀转绝对 URL |
| `getCode()` | `(): int` |

### 6.5 `Cache`

| 方法 | 说明 |
| --- | --- |
| `set` / `get` / `delete` / `has` | 默认 TTL `CACHE_TTL`；文件键 `md5($key).'.cache'`，原子写 tmp+rename |
| `remember` | 单航班锁 + 锁内双重检查 |
| `deleteByPrefix` | Redis `SCAN + UNLINK`；文件驱动扫内嵌 key |
| `nsVersion` / `bumpNsVersion` / `bumpNsVersionThrottled` | 命名空间版本，TTL 604800，节流窗口默认 20 秒 |
| `flush` | 只删 `*.cache`、`lock_*.lock`、`*.tmp`、遗留 `.index` |
| `withLock` | `flock(LOCK_EX)`，失败降级非原子 |

### 6.6 Hook 与 Plugin

| 类 | 公开静态方法 |
| --- | --- |
| `Hook` | `addFilter($tag,$cb,$priority=10)`、`applyFilter($tag,$value,...$args)`、`hasFilter($tag)`、`addAction($tag,$cb,$priority=10)`、`doAction($tag,...$args)`、`hasAction($tag)` |
| `Plugin` | `defer(callable)`、`runDeferred()`、`pluginDir()`、`loadAll()`、`loadAdminScoped()`、`loaded()`、`scanAll()` |

`Hook` 用驼峰命名。Filter 按 `priority` 升序执行。插件可用钩子与 docblock 元信息见 `docs/插件开发说明书.md`。

### 最小控制器

```php
<?php
namespace Hublog\Controllers;

use Hublog\Core\BaseController;
use Hublog\Core\Request;
use Hublog\Core\Response;

class ExampleController extends BaseController
{
    public function index(Request $request): Response
    {
        $name = $request->getString('name', '');
        return Response::success(['name' => $name]);
    }
}
```

```php
$router->get('/example', [Hublog\Controllers\ExampleController::class, 'index']);
```

类名与文件名一致，`public function xxx(Request $request): Response`，返回 `Response::success()` 或 `Response::error()`。

| 主题 | `templates/<id>/` | `docs/主题开发说明书.md` |
| 插件 | `plugins/<name>/` | `docs/插件开发说明书.md` |

主题新增页面只需在主题目录放同名 `.html`。插件有两条加载路径：API 入口 `Plugin::loadAll()` 调插件 `init()` 注册业务钩子与路由；管理端在管理员鉴权通过后由 `Plugin::loadAdminScoped()` 受控加载，只调 `registerAdmin()`，**绝不调 `init()`**。前台模板入口与后台 SPA 骨架本身不直接加载插件。

### 8.5 插件后台扩展点

后台插件能力不是「完全不加载」，而是受控加载（`Plugin::loadAdminScoped()`，`api/core/Plugin.php:124-196`）：

| 组成 | 位置 / 作用 |
| --- | --- |
| `Plugin::loadAdminScoped()` | `api/core/Plugin.php:124-196`；只加载「已启用 + 清单有 `admin_menu` / `admin_settings` 声明 + 核心版本兼容」的插件，定义 `HUBLOG_ADMIN_SCOPE`，只调 `registerAdmin()`，不调 `init()` |
| `PluginAdminContext` | `api/core/PluginAdminContext.php`；只读上下文，只暴露 `addMenu()` / `registerSettings()` 与 `menus()` / `settings()`，不持有 Database / Cache / Router |
| `AdminPluginController::adminConfig()` | `api/controllers/AdminPluginController.php`（按 `类::方法` 定位，不写行号）；`GET /api/admin/plugin-admin-config` 汇总菜单与设置声明，对声明删表的插件附带 `drop_confirm_token` |
| 后台消费 | `admin/js/nav-ui.js` 鉴权后请求该接口，动态注入侧栏菜单（无 `data-module`，不进模块门禁）；`admin/js/plugin-settings.js` 渲染设置页 |

插件后台声明与 `registerAdmin()` 的写法见 `docs/插件开发说明书.md` §16；主题与插件的常规开发步骤仍分别见两份专项说明书。

## 9. 测试与门禁

| 命令 | 作用 |
| --- | --- |
| `php api/tests/run_tests.php` | 自带 TestCase stub 的护栏测试，无需数据库 / composer |
| `vendor/bin/phpunit -c phpunit.xml.dist` | `behavior` + `unit` 套件 |
| `php scripts/ci.php` | 全量门禁；`--lint-only` 只跑语法 |
| `php scripts/build_migration_contract.php --check` | 迁移契约一致性，过期 exit 1 |
| `node scripts/audit-theme.js` | 主题 DOM 契约；`--gen --theme=<id>` 生成 |
| `php scripts/audit-admin-js.php` | 后台 JS 静态审计，高危项 >0 exit 1 |
| `php -l <file>` | 单个 PHP 文件语法 |
| `node --check <file>` | 单个 JS 文件语法 |

`scripts/ci.php` 六项：PHP ≥ 8.1、敏感文件未入库、composer 一致性、全量 `php -l`、护栏测试 + 迁移契约、PHPUnit（behavior + unit）；随后 6.5 PHPStan（level 3）为硬门禁，缺工具或分析出错误都会记入 `$failures` 并以退出码 1 结束，CI 需先跑 `php scripts/install-phpstan.php`（未安装不再跳过）；6.6 主题 DOM 审计有 node 才跑、缺 node 仅 WARN、审计失败阻断；6.7 五项静态审计为硬门禁（`audit-admin-js.php`、`audit-auth-guards.php`、`check-log-usage.php`、`check-inline-sql.php`、`check-unique-index-ddl.php`，退出非 0 即阻断），幂等键核验缺环境、运行时体检与主题同步为 WARN 不阻断；6.8 路由 / OpenAPI 对账为硬门禁（`parse_routes.php` 解析路由，`check_route_docs.php` 用冻结基线拦截新增路由未入文档与差异扩大）。

| 环境项 | 值 |
| --- | --- |
| PHP | 运行 ≥ 8.0（推荐 8.1）；CI ≥ 8.1 |
| 运行扩展 | `PDO`、`PDO_MySQL`、`GD`、`JSON`、`cURL`（`fileinfo` 推荐） |
| CI 扩展 | `dom`、`json`、`libxml`、`mbstring`、`openssl`、`pdo_sqlite`、`tokenizer`、`xml`、`xmlwriter` |
| 行尾 | 仓库未声明 `.gitattributes`，`git check-attr text eol -- <file>` 均为 `unspecified`，不强制 LF/CRLF；`core.autocrlf=true` 仅为本机 Git 配置，不代表仓库规则，工作区行尾以各自检出环境为准 |
| 比对差异 | `git -c core.autocrlf=false archive HEAD` 或 `git show :file` |

## 10. 代码约定

| 项 | 规则 |
| --- | --- |
| 命名空间 | `Hublog\Core`、`Hublog\Controllers`、`Hublog\Middleware`、`Hublog\Plugin\{name}`、`Hublog\Bootstrap` |
| 全局变量 / 常量 | `HUBLOG_BASE_URL`、`HUBLOG_URL_REWRITE`、`HUBLOG_PAGE_BASE`、`HUBLOG_FOOTER_DATA`、`$GLOBALS['hublog_access_*']`、`__THEME_OPTIONS__` |
| 请求头 | `X-Hublog-Fingerprint`、`X-CSRF-Token`、`X-Client-Type`、`X-Cron-Token` |
| Cookie | `hublog_token` |
| PHP 块注释 | 注释内不写 `*/` 组合，会提前闭合 docblock；改完跑 `php -l` |
| 迁移 DDL | `try/catch` 静默吞错，末尾必须有终态自检 |
| 帖子查询 | 所有涉及帖子的 `SELECT` 带 `p.post_type`，类型帖附加数据由对应 `build*Data` 装配 |
| 类型帖正文 | 问答 / 组队 / 打卡 / 投票正文存独立表，`posts.content` 留空 |
| 关注关系 | `follows` 无 `user_id` 列，子查询别名需加前缀避免歧义 |
| 用户表 | `users` 无 `token` 列，JWT 无状态；`token_version` 用于失效，刷新令牌散列存 `refresh_tokens.token_hash` |
| 内联脚本 | HTML 模板里 `<script` 与 `</script>` 数量必须相等 |
| 用户内容 | 展示层统一走 `renderMarkdown()`，不直接 `v-html` 原始字符串 |
