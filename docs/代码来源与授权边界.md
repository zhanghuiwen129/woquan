## 3.1 站点元数据上报（合规声明）

为核验源码是否被授权使用，本站会在安装完成及日常请求中，向源码授权中心发送**站点级元数据**（心跳上报）。本声明与上述两层授权体系一致：上报仅服务于授权核验与统计，不改变层 A / 层 B 的权属划分，也不构成对访客个人信息的处理。

| 上报字段 | 来源 | 用途 |
| --- | --- | --- |
| `installation_id` | 安装时生成并持久化的随机 UUID v4 | 标识安装实例；与域名、host、访问 IP 无关，重装 / 换域名保持不变 |
| `fingerprint` | 站点硬件环境信息的 SHA-256 摘要 | 辅助识别同一安装实例，交叉验证 |
| `license_code` | 站点配置的授权码（未配置时为空串） | 判定授权状态（有效 / 未登记 / 已吊销等） |
| `site_host` | 当前访问的主机名或纯 IP（去端口） | 仅作展示，可变化、可被伪造，不参与身份判定 |
| `version` | 源码版本号 | 统计版本分布 |
| `users` / `posts` | 全站启用状态的用户数 / 动态数聚合计数 | 统计规模，**不含任何个人字段** |
| `timestamp` / `nonce` | 请求时间与一次性随机串 | 防重放 |
| `signature` | 对上述字段的 HMAC-SHA256 签名（hex） | 服务端验签后才入库 |
| `server_ip` | **由授权中心记录自身的 `REMOTE_ADDR`** | 站点公网出口 IP；客户端不采集、不上报 |

**明确不采集**：访客个人信息、访客 IP（`REMOTE_ADDR`）、站点内网 IP（`SERVER_ADDR`）、精确地理位置、通讯录、短信与通话内容等任何敏感个人信息；上报请求中不含用户昵称、手机号、邮箱、内容正文或交易记录。

**范围与影响**：上报使用短超时（连接 1 秒 / 总计 2 秒）且失败完全静默，不阻断、不修改本站任何功能与数据；未授权站点仅被统计告警，不会被远程停用、删数据或破坏。授权中心仅将上述字段用于授权核验、去重与统计，并按协议文本明示。请求体与请求头契约详见 `docs/API_接口手册.md`，对外可见措辞见 `api/core/AgreementTexts.php`。

## 4. 逐文件判定方法

模块清单用于快速归类；发生争议时以逐文件证据为准：

1. **文件头「修改记录」标注**：本项目对上游文件的实质性修改，已在文件头以 `修改记录（Apache-2.0 要求标注变更）` 注明，这是 Apache-2.0 第 4 条(b) 的要求。
2. **git 提交历史**：`git log --follow -- <file>` 与 `git blame` 可定位某段代码的引入提交与时间。
3. **目录归属**：`app-client/`、`docs/`、`_analysis/` 与 `plugins/` 下的新增插件目录均为本项目新增；`api/core/` 中带新命名空间的类（如 `VisibilityPolicy`、`License`）为本项目新增。

新增文件应在文件头标注版权，示例：

```php
<?php
/**
 * Copyright 2026 woquan. All rights reserved.
 * 本文件为本项目新增代码，商业使用须取得书面授权。
 */
```
