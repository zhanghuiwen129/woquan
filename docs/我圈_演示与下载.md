## 源码获取

```bash
git clone https://gitee.com/aiwoquan/woquan.git
cd woquan
git log -1 --oneline     # 查看当前版本对应的提交
```

- 当前版本标识：`v2.17.00`（`config.example.php` 的 `APP_VERSION`），数据库迁移版本 101。
- 公开仓库只发布 PHP 后端；客户端工程、内部分析文档与 `.workbuddy/` 不在公开范围。
- 开源协议：Apache License 2.0，见仓库根目录 `LICENSE` 与 `NOTICE`。
- 部署步骤见[全新安装指南](./我圈_全新安装指南.md)。

## 本地预览

不做完整安装也可以先启动接口与页面查看结构：

```bash
php -S 127.0.0.1:8899 -t .
# 浏览器打开 http://127.0.0.1:8899/ 与 http://127.0.0.1:8899/admin/index.html
```

完整功能仍需通过 `install.php` 完成数据库初始化，不要在预览状态下当作生产环境使用。

主题外观可直接查看仓库内的预览图：

| 主题 | 预览文件 | 定位 |
| --- | --- | --- |
| `moments` | `templates/moments/preview.svg` | 朋友圈风格，官方默认 |
| `zixunfeed` | `templates/zixunfeed/preview.svg` | 沉浸式资讯流 |
| `shaiboblog` | `templates/shaiboblog/preview.svg` | 赛博博客三栏布局 |

移动端截图位于 `assets/app-publish.jpg`、`assets/app-home.jpg`、`assets/app-mine.jpg`。

## 客户端

- **H5**：在 uni-app 工程执行 `npm install && npm run build:h5`，把产物放到站点 `h5/` 目录。
- **Android / iOS**：用 HBuilderX 打开客户端工程，调试后云打包；接口域名与媒体地址配置见[升级部署指南](./我圈_升级部署指南.md)。
- **现成安装包**：以官网公布的下载入口为准。

## 接口调试

| 资源 | 用途 |
| --- | --- |
| `docs/API_接口手册.md` | 鉴权、错误码、接口清单与调用约定 |
| `docs/openapi.yaml` | OpenAPI 契约，可导入 Apifox / Postman 等工具 |
| `docs/hublog-app.postman_collection.json` | 30 个常用请求的 Postman 集合 |
| `api/routes.php` | 路由唯一真源，文档与实现不一致时以它为准 |

本地接口示例：

```bash
curl -s http://127.0.0.1:8899/api/health
curl -s http://127.0.0.1:8899/api/site/config
```
