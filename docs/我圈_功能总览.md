# 我圈 功能总览

> 我圈，全称「我圈轻量可模板化的多形态内容社区系统」，简称「我圈」。
> 本文按源码中的模块注册表、功能开关与内置插件整理，用于快速判断需要开启哪些能力。配置项以 `api/core/ModuleCatalog.php`、`api/core/License.php` 与各插件清单为准。

## 1. 站点模式

同一套程序通过「站点模式 + 模块开关 + 主题」组合出不同形态。模式在后台「站点设置」一键切换，也可选 `custom` 逐项微调。

| 模式 | 定位 | 开启的模块 | 前台形态 |
| --- | --- | --- | --- |
| `social` | 社交 / 兴趣社区 | 14 个（除内容付费外全部） | 五种帖型、完整发布工具栏、发布 / 搜索 / 消息 / 收藏 / 我的导航 |
| `blog` | 博客 / 企业内刊 | 5 个：评论、友链、举报、申诉、敏感词 | 仅普通文章，写作走文章编辑器，收起社交发布与消息 / 收藏入口 |
| `news` | 资讯站 | 7 个：在博客基础上加话题、精华 | 普通 / 投票 / 问答帖，保留话题与草稿 |
| `content` | 内容付费 / 知识社区 | 9 个：资讯能力 + 财务会员 + 内容付费 | 文章型内容流与付费阅读 |
| `custom` | 自定义 | 在预设基础上单独开关 | 由关闭的功能与守卫规则决定 |

模块依赖会强制校验：`contentpay` 依赖 `finance`，`shop` 依赖 `finance`，`appeals` 依赖 `reports`。

## 2. 可关模块（15 项）

| 模块 key | 名称 | 作用 |
| --- | --- | --- |
| `comments` | 评论管理 | 评论审核、删除与用户评论记录 |
| `topics` | 话题管理 | 话题标签与话题动态聚合 |
| `featured` | 精华管理 | 全站精华与首页精选 |
| `friend_links` | 友情链接 | 前台友链展示 |
| `circles` | 圈子管理 | 圈子、成员与圈内动态 |
| `chat` | 私信管理 | 单聊 / 群聊、会话与音视频通话 |
| `activities` | 活动管理 | 活动发布与报名 |
| `badges` | 徽章管理 | 徽章配置与定时扫描 |
| `realname` | 实名认证 | 实名核验与审核记录 |
| `reports` | 举报管理 | 用户举报与处理 |
| `appeals` | 申诉管理 | 处罚申诉与复核 |
| `shop` | 商城管理 | 商品与积分大转盘 |
| `finance` | 财务会员 | 支付、钱包、会员与积分 |
| `contentpay` | 内容付费 | 单篇买断与专栏订阅 |
| `safety_filter` | 敏感词与命中记录 | 后台两个管理页；关闭不影响本地过滤链 |

后台常驻 13 页（仪表盘、用户、内容、分类、附件、设置、统计、导出、插件、授权、升级、客户端版本、崩溃日志）不受模块开关影响。模块关闭后，对应后台菜单隐藏，运行层按接口前缀拦截，访问日志按同一前缀归因到模块或 `core`。

## 3. 内容能力

- **帖型**：`normal`（普通）、`poll`（投票）、`question`（问答）、`team`（组队）、`checkin`（打卡）五种，由 `posts.post_type` 标记。
- **可见范围**：`public`（所有人）、`circle`（有效圈子成员，付费圈还要求订阅有效）、`friend`（当前用户单向关注作者）、`private`（仅作者）。缺失或非法值按默认拒绝处理。
- **互动**：点赞、评论、收藏、转发、@提及；话题自动识别；精华与置顶。
- **媒体**：图片、视频、附件；Vditor / Markdown 正文与 `[[media:<type>:<index>]]` 媒体占位符；视频转码依赖 FFmpeg。
- **治理**：敏感词三档过滤、内容审核状态（正常 / 待审 / 通过）、举报与申诉、实名认证姓名脱敏。

## 4. 主题与前台

| 主题 | 定位 | 正文格式 |
| --- | --- | --- |
| `moments` | 官方默认，朋友圈风格，作为其它主题的契约基准 | Markdown |
| `zixunfeed` | 沉浸式资讯流，固定顶栏 + 频道 Tab + 首屏 SEO | HTML |
| `shaiboblog` | 赛博博客，三栏布局、分类 / 归档 / 标签侧栏 | Markdown |

三套主题都支持深色模式与自定义配色，均通过契约门禁校验。主题切换后需清除 `site_settings` 缓存才能在前台即时生效。开发新主题见[主题开发说明书](./主题开发说明书.md)。

## 5. 内置插件

| 插件 | 作用 |
| --- | --- |
| `AiComment` | 新动态发布后异步生成一条 AI 评论；任务由 `/api/cron/jobs` 消费，未配置该 cron 时静默失效 |
| `ContentAudit` | 双层审核：本地 DFA 敏感词 + AI 语义判定，命中后把内容置为待审 |
| `DemoExtension` | 二开示例，演示清单建表、设置页配置与业务钩子，不含垂直业务 |
| `SmartRecommend` | 基于行为协同过滤 + 标签内容 + 时间衰减热度的个性化推荐，纯规则、不调用 AI |
| `SmartSearch` | MySQL LIKE 搜索 + 向量语义搜索，向量生成由 cron 异步执行，插件默认关闭 |
| `SmartSummary` | 发帖后生成摘要与标签，摘要写入 `posts.summary`，标签写入 `post_tags` |

插件通过 `plugin.json` 声明元信息、声明式建表与配置；启用状态以 `plugin_states` 为准，配置存 `plugin_configs`。后台插件页面只加载声明了后台入口且已启用的插件，不会执行前台 `init()`。开发规范见[插件开发说明书](./插件开发说明书.md)。

## 6. 商业化与授权

- **付费兴趣社群**：圈子订阅支持包月 / 季 / 年，到期自动清退并提醒（依赖 `/api/cron/circle-subscribes`）。
- **内容付费**：单篇买断与专栏订阅，可用余额与积分抵扣；未购买用户仅拿到试读内容，权益表是唯一权威。
- **通用能力**：钱包、积分、会员、在线充值、订单；与内容付费共用账户体系。

授权模块共 8 项：`ai`、`scheduled`、`dataops`、`circles`、`shop`、`finance`、`activities`、`realname`。`badges`、`points`、`moderation` 为免费核心能力，始终可用；发布、私信与会话属基础社交能力，不作授权模块，仅受配额约束。未授权时 AI 走每日限量试用，其余受限模块拒绝访问。

## 7. 客户端与接口

- **Web / H5**：主题自带响应式页面；`assets/` 提供静态资源。
- **移动端**：uni-app 工程产出 Android / iOS / H5，公开仓库不含客户端源码；域名配置见[升级部署指南](./我圈_升级部署指南.md)。
- **API**：接口契约见[API 接口手册](./API_接口手册.md)与 `openapi.yaml`；路由唯一真源为 `api/routes.php`。
